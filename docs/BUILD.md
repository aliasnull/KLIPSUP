# KLIPSUP Build & Native Configuration Guide

## 1. Application Identity
- **Application Name**: `KLIPSUP`
- **Package / Namespace**: `alias.klips.net`
- **Minimum SDK**: 26
- **Target / Compile SDK**: 36

## 2. Build Commands
- Assemble Debug APK: `gradle :app:assembleDebug`
- Run Unit & Robolectric Tests: `gradle :app:testDebugUnitTest`
